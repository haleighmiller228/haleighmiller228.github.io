### _Artifact Introduction_
  For my ePortfolio, I chose to focus on making multiple enhancements to the same artifact; the artifact I chose to modify was the Inventory Tracking Application originally created for use on Android devices in CS-360 Mobile Architecture and Programming. The application was created to track the inventory of various products in a warehouse in order to make inventory management and order packing easier and more efficient for the employees of the warehouse. This artifact was the first fully-functional application I had ever created, and being able to see the program go from written code to an application user interface that responded to clicks like a real smart phone application was very exciting. Being an iPhone user, I wanted to see what coding in Swift was like, and I also wanted to see an application brought to life on an iOS device. For these reasons, I chose to demonstrate my Software Design and Engineering skills by porting the Inventory Tracker Application over to the Swift language, including all the functionalities created in the original Android application. 
  
  After porting over the existing functionalities of the application and creating the iOS user interface, I made more modifications to the same application to demonstrate my skills in Algorithms and Data Structure as well as Databases. For the former, I chose to add a new function to the application that would automatically send an email to the inventory manager when the stock of an item(s) is below a pre-determined threshold. This new algorithm is triggered by the click of a button, then checks each item’s current inventory and compares it to the item’s low-stock threshold, and adds the item to the reorder email before it is sent. Adding this functionality to the application eliminates the inventory manager’s need to constantly check each item’s inventory levels, allowing them to simply reorder the items flagged by the application’s algorithm. 
  
  Finally, to demonstrate my skills in Databases, I chose to expand on the information that the application already stored about the items and the users of the application. I added several fields to the item entity to provide more detailed information about each item; in addition to the item’s name and inventory level, the application can now show a photo and description of the item, as well as the item’s location in the warehouse and the previous month’s sales rate of the item. For the user entity, I added new fields on top of the user’s login information to store a photo of the user, as well as the user’s job title and department. With the development of secure login authentication, the application could ensure that only users with the right credentials are able to access certain parts of the application, such as modifying low-stock thresholds.
